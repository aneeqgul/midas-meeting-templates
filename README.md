# Meeting minutes and action-item template

A plain-text template for recording decisions, agreed actions and open questions. Download the file and fill it in locally in any notes app. No account is needed to use the template.

[Download the template](MEETING_MINUTES_TEMPLATE.txt) · [Read the worked example](https://midas-products.midas-cloud-control-plane.workers.dev/guides/meeting-minutes-action-items-template?utm_source=github&utm_medium=owned&utm_campaign=meeting_template)

## Use it after a meeting

1. Add the meeting title, date, time zone, attendees and purpose.
2. Record decisions with the words or notes that support them.
3. Add each action, its explicitly agreed owner and deadline. Leave missing commitments unspecified rather than guessing.
4. List open questions and ask participants to correct the minutes before sharing.

The included example is fictional and was written to illustrate the method. It is not a customer result or a product run. Keep confidential notes out of public issues and pull requests; edit your own copy locally.
